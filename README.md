# CyberShield

CyberShield est une application web de sensibilisation à la cybersécurité. Elle regroupe quatre outils interactifs : un analyseur de mot de passe, un détecteur d'e-mails phishing, un quiz de sensibilisation et un module de cryptographie de messages. Tout tourne dans le navigateur, sans backend ni dépendance externe.

## Fonctionnalités

**Analyseur de mot de passe** : évalue la robustesse d'un mot de passe en temps réel.

**Détecteur de phishing** : analyse un e-mail et repère les indices suspects typiques d'une tentative de hameçonnage.

**Quiz interactif** : série de questions pour tester ses connaissances en cybersécurité.

**Cryptographie** : permet de chiffrer et déchiffrer des messages.

## Lancer le projet

Aucune installation requise. Il suffit d'ouvrir le fichier `index.html` dans un navigateur.

Ou via une extension comme Live Server sur VS Code.
